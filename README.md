# Silhouette
블라인드 랜덤 매칭과 프로필 탐색을 모두 지원하는 소개팅 플랫폼


# 프로젝트명

> 블라인드 랜덤 매칭과 프로필 탐색을 모두 지원하는 소개팅 플랫폼

## 📌 프로젝트 소개
- 개발 기간: 2026.00.00 ~ 2026.00.00
- 개발 인원: 4명
- 한 줄 요약: 블라인드 매칭과 프로필 탐색으로 만나고, 채팅을 거쳐 실제 만남까지 이어주는 서비스

## ✨ 주요 기능
| 구분 | 기능 |
|---|---|
| 매칭 | 블라인드 랜덤 매칭 / 프로필 탐색(이상형 추천 + 랜덤 리스트) |
| 채팅 | 시간제한 채팅(Go/Stop), AI 추천 답변, 그룹채팅(2:2, 3:3) |
| 회원 | 본인인증, 프로필 등록(사진, MBTI, 선호 취향) |
| 기타 | 지도 기반 주변 찾기, QR 만남 인증, 라이브 방송 |

## 🛠 기술 스택
- Backend: Java, Spring
- Frontend: HTML, CSS, JavaScript
- DB: MySQL (또는 Oracle)
- Tools: GitHub, Notion, Figma
